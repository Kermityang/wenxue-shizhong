你在为一个中文文学时钟挑选句子。请给我 20 句「只写了时辰或天光」的文学原句，质量优先于数量。

选句要求：
1. 必须出自真实存在的文学作品，并准确标注作者与书名/篇名。不得编造作品、作者、出处或引文；外国作品引用已发表的中译文，不要自行翻译。
2. 每句 12–80 字，从原文完整截取，不得改写、拼接或补写。优先选择意象鲜明、能独立阅读的句子。
3. 句子写时辰、更次、晨昏、天光或月景，如「三更」「晌午前后」「日头偏西」「月上柳梢」，且能合理对应一天中的一个或数个整点。明确几点几分的句子不要；只有年月日、季节或节日而无法判断一天中时段的也不要。
4. 尽量覆盖不同时段，句子不得重复。

每条只能有 s、b、h、time、seg、tier、scope 七个字段：
- s：句子原文，JSON 字符串。
- b：出处，JSON 字符串，格式为「作者　《书名/篇名》」。
- h：若 s 中有时辰、更次等时间词，填该词的原文，必须是 s 的连续子串，一字不改；没有可摘出的时间词则填空字符串 ""。不得填句外推测的词。
- time：固定为空字符串 ""。
- tier：固定填 2（精准句=1，写意句=2）。
- scope：固定填 "segment" 或 "wide"。
- seg：该句可能覆盖的整点，必须是非空的 JSON 字符串数组；每个元素只能是 "0"、"1"……"23" 这样的小时字符串，不能写数字、"00" 或 "23:00"，不要重复。按时段先后顺序排列，可以跨午夜，例如「三更」是 ["23","0","1"]，「晌午」是 ["11","12","13"]。seg 必须与 h（非空时）或 s 中的天光意象相符，不得随意扩大范围。

输出前逐条自检：非空的 h 确实原样出现在 s 中，time 为空字符串，seg 的类型、取值和顺序正确且与句意一致，字段齐全。任何一条不满足就删除。若确认无误的不足 20 句，宁可少给也不要编；一句也确认不了就输出 []。

只输出合法 JSON 数组，不要 markdown 代码块，不要注释、前后解释或多余文字，不要尾随逗号。

正例（仅示范格式与字段关系，不要照抄）：
[{"s":"夜饮东坡醒复醉，归来仿佛三更。","b":"苏轼　《临江仙·夜归临皋》","h":"三更","time":"","seg":["23","0","1"],"tier":2,"scope":"segment"}]
